ITALIA: SABORES DE TRADICIÓN
=============================

Archivos:
- index.html    -> Página principal
- platos.html   -> Subpágina de platos tradicionales
- recetas.html  -> Subpágina de recetas
- estilos.css   -> Estilos del sitio

INSTRUCCIONES:
1. Descarga y descomprime la carpeta.
2. Abre index.html en Google Chrome, Edge o Firefox.
3. Para editar el proyecto, abre la carpeta en Visual Studio Code.

NOTA:
Los recuadros de "FOTOGRAFÍA" y "MAPA DE ITALIA" son espacios reservados para agregar imágenes reales posteriormente.
El sitio incluye prácticas básicas de accesibilidad: HTML semántico, texto alternativo descriptivo en espacios de imágenes, enlace para saltar al contenido, navegación con teclado, contraste y diseño adaptable.
